# PRONOM submission: ABook Audiobook File

Prepared for https://github.com/digital-preservation/PRONOM_Research (new format, submitted as a pull request into
`Submissions/ABook Audiobook File/` with this text and a sample file).

* **Format name:** ABook Audiobook File
* **Version number:** 1
* **PUID:** none yet
* **Extensions:** abook
* **MIME/Media Type:** application/vnd.ngdtuanh.abook+zip (vendor tree; IANA registration requested 2026-10-01; also
  defined in the vendor's specification below)
* **Description:** A ZIP-based container for one finished audiobook, written by ABook, an audiobook production and
  listening application for Windows and Android. It holds the MP3 audio of every chapter (stored uncompressed), the book
  text with the speaker, emotion and timing of each line (JSON), the cast of characters with short WAV voice samples, a
  JPEG cover, and a Readium Audiobook manifest. The first entry is an uncompressed file named `mimetype` containing the
  media type, as in EPUB. Specification:
  https://github.com/ntanhpro1221/ABook/blob/main/_internal/docs/ABOOK_FILE_FORMAT.md
* **Format type:** Audio (container / aggregate)
* **Vendor:** ABook (Nguyễn Duy Tuấn Anh), https://github.com/ntanhpro1221/ABook
* **Signature (BOF):** offset 0: `504B0304`; offset 30: `6D696D6574797065` (`mimetype`) followed immediately by
  `6170706C69636174696F6E2F766E642E6E67647475616E682E61626F6F6B2B7A6970`
  (`application/vnd.ngdtuanh.abook+zip`). Container signature: ZIP entry `mimetype` with that exact content.
* **Attribution:** Nguyễn Duy Tuấn Anh, ABook
* **Sample:** `sample.abook` - a short public-domain test book generated by ABook (silent audio, no third-party text).
